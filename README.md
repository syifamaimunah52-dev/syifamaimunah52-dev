# ♟️ Simple Web Chess Game

Game catur sederhana berbasis web yang dibuat menggunakan **HTML**, **CSS**, dan **JavaScript**. Proyek ini dirancang ringan tanpa memerlukan instalasi library atau dependensi tambahan—cukup buka di browser dan langsung mainkan!

---

## ✨ Fitur Utama
* **2-Player Local Mode**: Bisa dimainkan berdua secara bergantian di perangkat yang sama.
* **Unicode Chess Pieces**: Menggunakan simbol Unicode murni untuk bidak catur tanpa perlu aset gambar eksternal.
* **Responsive & Clean UI**: Tampilan papan catur klasik dengan desain modern yang bersih dan antarmuka interaktif.
* **Turn Indicator**: Menunjukkan informasi giliran pemain secara *real-time* (Putih atau Hitam).
